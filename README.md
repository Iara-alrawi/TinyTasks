# TinyTasks

TinyTasks is a SaaS-inspired task management application built with React and Firebase.

## Features
- User authentication (login/register)
- Create projects
- Add, edit and delete tasks
- Mark tasks as completed
- Real-time database updates

## Tech Stack
- React
- Firebase Authentication
- Firebase Realtime Database
- CSS

## How to run
npm install 
npm start
